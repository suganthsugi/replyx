# Tasks: Multi-Tenant Customer Support Platform

**Input**: Design documents from `specs/001-multi-tenant-helpdesk/`
**Prerequisites**: [plan.md](plan.md), [spec.md](spec.md), [research.md](research.md),
[data-model.md](data-model.md), [contracts/](contracts/README.md), [quickstart.md](quickstart.md)

**Tests**: Included. Constitution principle VII, SC-010 and SC-016 require automated tests for
authorization, tenant isolation, the ticket lifecycle, message routing and the main flow, and the
test-automator agent contract requires success / 403 / cross-tenant 404 cases for every endpoint.
Tests follow implementation within each story (the orchestrator runs backend → tests + frontend
→ connector → frontend tests), and a story is not done until its tests pass.

**Organization**: Tasks are grouped by user story. Phases run in **dependency order**, not spec
numbering: US3 (sign-in) comes before US2 (tenant lifecycle) because tenant creation invites an
admin, and US1 (customer chat) comes after the access model because staff must be able to reply.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an incomplete task)
- **[Story]**: the spec user story (US1–US18)
- Every task names the exact file(s) it creates or changes

## Path conventions (from plan.md)

| Path | Owner agent |
|------|-------------|
| `apps/api/src/`, `apps/api/migrations/`, `apps/api/openapi.yaml`, `apps/api/package.json` | backend-agent |
| `apps/api/test/` | test-automator |
| `apps/web/src/components/`, `apps/web/src/pages/`, `apps/web/src/theme/` | frontend-agent |
| `apps/web/src/data/` | frontend-connector |
| `apps/web/test/`, `apps/web/e2e/` | frontend-automator |
| `apps/docs/` | documentator (guides) / dev-documentator (developer docs) |
| Repo root, `infra/`, `.github/`, `apps/*/Dockerfile`, `apps/web/src/routes/`, `apps/web/*.config.ts`, `apps/web/public/` | **No agent owns these yet.** Setup, Deploy, and a few story tasks touch them; the orchestrator will ask who does them (see Notes) |

`apps/web/src/api/generated/` is generated by `bash scripts/generate-api-client.sh` after each
backend task that changes `apps/api/openapi.yaml`. It is never edited by hand.
