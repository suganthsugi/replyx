ReplyX is a multi-tenant help desk. This site collects the guides, admin
reference, operator runbooks and developer documentation for the project.

- **Guides** — end-user and agent workflows in the help desk.
- **Admin** — configuring a tenant: users, roles, routing, SLAs, views.
- **Operators** — deploying, monitoring and operating the platform.
- **Developers** — module boundaries, domain events, tenancy and
  authorization, real-time/outbox flow, and how to add a module.

For the generated HTTP API reference (rendered by Scalar from
`apps/api/openapi.yaml`), see **API reference** in the sidebar.
